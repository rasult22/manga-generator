# Техническое задание: MangaFlow MVP
## AI-assisted storytelling tool для создателей манги

---

## 1. Концепция продукта

**Проблема:** Начинающие авторы манги имеют идеи, но не знают, как структурировать мир, персонажей и сюжет. Линейные инструменты заставляют работать в определенной последовательности, что убивает творческий процесс.

**Решение:** Мобильное приложение с **модульной нелинейной системой создания**. Пользователь может начать с любого элемента (персонаж, мир, событие, локация) и использовать AI для генерации связанных элементов. AI не работает автоматически — он помогает с промптами и учитывает выбранный контекст.

**Целевая аудитория:**
- Новички без опыта в создании манги
- Люди с идеями, но без навыков рисования
- Любители, желающие быстро прототипировать историю

**Ключевые принципы:**
1. **Нелинейность:** Начни с чего хочешь — персонаж, мир, событие
2. **Контекст-инжиниринг:** AI использует существующие элементы для генерации связных новых
3. **Контроль пользователя:** AI предлагает, но не решает за тебя — ты пишешь промпт и выбираешь контекст
4. **Entity-based архитектура:** Проект = коллекция независимых сущностей с связями

---

## 2. Платформа и технологии

- **Framework:** Expo 54 (React Native)
- **Navigation:** Expo Router
- **Локальное хранилище:** AsyncStorage / Expo SQLite
- **AI Integration:** (будущая фаза) REST API для text/image генерации
- **UI Kit:** React Native Paper / Tamagui / NativeWind
- **Drag-and-drop:** react-native-draggable-flatlist

## 3. Архитектура данных

### 3.1 Структура проекта (Entity-Based)

```typescript
type Project = {
  id: string;
  name: string;
  entities: Entity[]; // Все элементы проекта
  episodes?: Episode[]; // Опциональные собранные эпизоды
  settings: {
    defaultStyle: 'anime' | 'realistic' | 'sketchy';
    genre?: string; // Опционально, не обязательно при создании
  };
  createdAt: number;
  updatedAt: number;
};
```

### 3.2 Базовый тип Entity

```typescript
type Entity =
  | CharacterEntity
  | WorldEntity
  | LocationEntity
  | StoryBeatEntity;

// Общие поля для всех entities
interface BaseEntity {
  id: string;
  type: 'character' | 'world' | 'location' | 'story';
  name: string;
  linkedTo: string[]; // ID связанных entities
  createdAt: number;

  // Метаданные AI-генерации
  generationMetadata?: {
    generatedFrom?: string; // ID родительской entity
    userPrompt?: string; // Промпт пользователя
    usedContext?: string[]; // ID entities использованных в контексте
    timestamp: number;
  };
}
```

### 3.3 Character Entity

```typescript
interface CharacterEntity extends BaseEntity {
  type: 'character';
  role?: 'protagonist' | 'antagonist' | 'support';
  age?: number;
  traits: string[]; // Черты характера
  motivation?: string;
  backstory?: string;
  appearance?: string; // Описание внешности
  referenceImage?: string; // base64 reference image для AI
}
```

### 3.4 World Entity (элемент лора)

```typescript
interface WorldEntity extends BaseEntity {
  type: 'world';
  category: 'magic' | 'tech' | 'society' | 'history' | 'rules' | 'other';
  description: string; // Описание элемента мира
  // Примеры: "Magic System: Runes on skin", "Tech Level: Cyberpunk 2077"
}
```

### 3.5 Location Entity

```typescript
interface LocationEntity extends BaseEntity {
  type: 'location';
  description: string;
  visualReference?: string; // base64 изображения локации
  associatedCharacters?: string[]; // Персонажи связанные с локацией
}
```

### 3.6 Story Beat Entity (сюжетная точка)

```typescript
interface StoryBeatEntity extends BaseEntity {
  type: 'story';
  description: string; // Описание события
  involvedCharacters?: string[]; // ID персонажей
  location?: string; // ID локации
  timing?: 'past' | 'present' | 'future'; // Временная привязка
}
```

### 3.7 Episode (собранный эпизод)

```typescript
type Episode = {
  id: string;
  title: string;
  storyBeats: string[]; // Ordered list of StoryBeatEntity IDs
  structure?: {
    ki: string;        // 起 - Introduction
    sho: string;       // 承 - Development
    ten: string;       // 転 - Twist
    ketsu: string;     // 結 - Conclusion
  };
  panels: Panel[];
  involvedCharacters: string[]; // Character IDs
  createdAt: number;
};
```

### 3.8 Panel (кадр манги)

```typescript
type Panel = {
  id: string;
  order: number;
  description: string;
  shotType: 'wide' | 'medium' | 'close-up' | 'extreme-close';
  characters: string[]; // Character IDs
  location?: string; // Location ID
  dialogue?: string;
  generatedImage?: string; // base64
  aiPrompt?: string; // Финальный промпт для генерации
};
```

## 5. AI Integration Strategy

### 5.1 Context Engineering

**Структура AI-запроса:**

```typescript
type AIGenerationRequest = {
  targetType: 'character' | 'world' | 'location' | 'story';
  userPrompt: string; // Написанный пользователем
  sourceEntityId?: string; // Откуда генерим (если из detail screen)

  context: {
    characters: CharacterEntity[];
    worldElements: WorldEntity[];
    locations: LocationEntity[];
    storyBeats: StoryBeatEntity[];
  };

  projectMetadata?: {
    name: string;
    genre?: string;
    style?: string;
  };
};
```

**Промпт для AI (example):**

```
System: You are a manga story consultant. Generate structured JSON output.

Project Context:
- Name: Cyber Rebellion
- Genre: Cyberpunk
- Style: Anime

Existing Entities:

Characters:
- Akira (Protagonist): Rebellious, Tech-savvy. Motivation: Revenge for family. Appearance: Spiky black hair, cyberpunk jacket.
- Yuki (Support): Loyal, Hacker. Motivation: Protect friends.

World Elements:
- Magic System: Runes carved on skin grant powers
- Tech Level: 2077, megacities, AI corporations

Locations:
- Tokyo Ruins: Abandoned district, hacker hideout

Story Beats:
- Family Massacre: Akira's family killed by corporate hit squad

─────────────────────

User Request:
Type: World Element
Source: Character "Akira"
Prompt: "Create a dystopian society where corporations control everything through technology"

─────────────────────

Generate a World Element (JSON):
{
  "name": "...",
  "category": "society" | "magic" | "tech" | "history" | "rules",
  "description": "...",
  "suggestedLinks": ["entity_id_1", "entity_id_2"]
}

Ensure it fits the existing context and source character.
```

### 5.2 AI Suggest Prompt (Help Button)

**Когда пользователь нажимает `💡 Help me write this`:**

```typescript
type PromptSuggestionRequest = {
  targetType: 'character' | 'world' | 'location' | 'story';
  sourceEntity?: Entity;
  selectedContext: Entity[];
};

// AI возвращает suggested prompt:
type PromptSuggestion = {
  prompt: string;
  reasoning?: string; // Опционально: почему такой промпт
};
```

**Example response:**

```json
{
  "prompt": "Based on Akira (rebellious hacker) and the Rune Magic System, create a dystopian megacity where technology and ancient magic collide, ruled by corrupt corporations that hunt down rune-users",
  "reasoning": "This world connects Akira's tech skills with the magical system, and creates natural conflict for his rebellious personality"
}
```

### 5.3 Auto-linking Entities

После генерации AI может предложить связи:

```json
{
  "name": "Neo-Tokyo Underground",
  "category": "society",
  "description": "...",
  "suggestedLinks": [
    "akira_character_id",
    "rune_magic_id",
    "tokyo_ruins_location_id"
  ]
}
```

Приложение автоматически добавляет эти ID в `linkedTo` поля.

## 7. UI/UX Принципы

1. **Нелинейность:** Пользователь сам выбирает последовательность создания
2. **AI как помощник:** AI никогда не генерит автоматически, только по запросу с контролем пользователя
3. **Контекст-видимость:** Всегда показывать что будет использовано для генерации
4. **Progressive disclosure:** Сложные формы сворачиваются (context preview)
5. **Mobile-first:** Оптимизация под вертикальный экран
6. **Offline-first:** Все работает локально
7. **Forgiveness:** Легко отменить (Regenerate, Edit, Delete)
